WHAT IS AI?

AI in one sentence

🧠

AI = Machines doing tasks that normally require human intelligence.

Examples: recognising faces, understanding language, making predictions, recommending products, detecting fraud.

REAL-WORLD ANALOGY

Think of AI like an intern.

👨‍💼 Human Intern

  • Receives examples
  • Learns patterns
  • Gets feedback
  • Uses knowledge to make decisions

🤖 AI System

  • Receives data
  • Learns patterns
  • Gets training signals
  • Produces predictions/output

AI does not “think” exactly like a human.

THE NEXT QUESTION

How does modern AI understand language?

💬

LLM

Large Language Model

Think of it as a giant language pattern learner.

LLM

What is an LLM?

Large

Trained using enormous amounts of text/data.

Language

Designed to work with human language.

Model

A mathematical system that learns patterns.

LLM ≠ database of sentences.

TOKENIZATION

AI doesn't read words exactly like you do.

Before an LLM processes text, it converts text into tokens.

Sentence

“I love Indian food.”

Possible tokens

I love Indian food .

Real tokenization can split words into smaller pieces.

THE BIG MISCONCEPTION

Does ChatGPT “look up” every answer?

Usually, no.

A language model generates text based on patterns learned during training and the context it receives.

Therefore: fluent ≠ automatically factual.

PROMPTS

So what is a Prompt?

Prompt = Instruction / input given to an AI.

Example:

“Explain inflation in simple language with an example of a ₹100 product.”

Think of a prompt as the brief you give to an intern.

PROMPT ENGINEERING

Bad prompt vs Better prompt

❌ Weak

“Explain marketing.”

✅ Better

“You are a marketing professor. Explain digital marketing to a first-year commerce student using a Zomato example in under 200 words.”

PROMPT FORMULA

A simple prompt formula

🎭 Role
+
🎯 Task
+
📚 Context
+
📐 Format
+
🚧 Constraints

Example: “Act as a business analyst. Analyse this sales table. Identify the top 3 products. Give the result as a simple table and mention one business recommendation.”

PROMPTING

Zero-shot vs Few-shot

Zero-shot

Ask without examples.

“Classify this review as positive or negative.”

Few-shot

Give examples first.

“Amazing → Positive
Terrible → Negative
Average → ?”

RAG

What if AI doesn't know your information?

RAG = Retrieval-Augmented Generation

Instead of asking the model to rely only on its learned knowledge, we first retrieve relevant information and provide it as context.

RAG ANALOGY

RAG = Open-book exam 📖

Normal LLM

“Answer using what you already know.”

RAG

“First search these documents. Then answer using the relevant information.”

This is extremely useful for company documents, policies, reports and knowledge bases.

RAG FLOW

How RAG works

👤 Question
→
🔎 Retrieve
documents
→
📚 Relevant
context
→
🧠 LLM
→
💬 Answer
RAG EXAMPLE

College Helpdesk Bot 🎓

Student: “What is the attendance requirement?”

RAG: Searches college handbook → finds attendance policy → gives answer.

Better than asking a general AI model to guess the college policy.

PRIVACY

Before you paste data into AI...

STOP 🛑

Ask: “Would I be comfortable if this information became public?”

Always understand the privacy, retention and enterprise policies of the AI tool you are using.
